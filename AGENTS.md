# Auto welder

The idea is to build a welding assistant robot using a i2rt YAM robotic arm, camera/lidar or some other close distance high resolution sensor for localization. Localization is to be done realtive to a provided CAD model as a step file. Need to position the robotic arm in the space relative to the CAD and then be able to locate joints. Welding would be done using a MIG welder whose torch would be 3d scanned eventually - but you can assume any torch for now. This project would be built in stages and every stage would need to be marked DONE by me before you start on the next one. If you see DONE on a stage, it means you can skip to the next one. 


## Robotic arm
You can find everything at https://github.com/i2rt-robotics/i2rt

This robot is being controlled by the canable pro USB to Can dongle. The robot is connected and live - so be careful and ask before issuing test commands.

## MIG welder
Assume a traditional MIG welder where you would only have on-off control over the trigger. Wire feed speed would be calculated per joint through trial and error. The robot's travel speed around the joint should be configurable.
